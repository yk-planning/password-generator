    パスワードジェネレーターの使い方

    1. 長さを選ぶ：スライダーまたは数値入力で 4〜128 文字の範囲から選びます。
    2. 強度を選ぶ：「低・中・高・最高」から用途に合ったものを選びます。迷ったら「高」がおすすめです。
    3. コピーして使う：8個の候補から好きなものを選び、「コピー」ボタンでクリップボードにコピーします。

    記号が使えないサービスなど、文字の種類に制限がある場合は「詳細設定」から使用する文字を個別に選べます。

    パスワード強度の目安

    パスワードの強さは「使う文字の種類」と「文字数」で決まります。文字の種類が多く、文字数が長いほど、総当たり攻撃で解読されにくくなります。

    強度使用する文字推奨文字数おすすめの用途
    低小文字・数字8文字〜一時的な利用、重要度の低いサービス
    中大文字・小文字・数字12文字〜記号が使えないサービス
    高大文字・小文字・数字・記号16文字〜メール・SNS・ネットショップなど一般的なサービス
    最高大文字・小文字・数字・記号32文字〜ネットバンキング・管理者アカウント・Wi-Fiなど重要な用途

    ※「解読にかかる時間の目安」は、1秒間に100億回の推測を行う攻撃を想定した平均値です。

    安全なパスワードを作る・管理するコツ

    • 使い回さない：サービスごとに異なるパスワードを設定しましょう。1か所から漏れると、他のサービスにも不正ログインされる危険があります。
    • 長くする：文字数を増やすことが、最も効果的に強度を上げる方法です。
    • 推測できる情報を避ける：名前・誕生日・電話番号・辞書にある単語は避けましょう。
    • パスワードマネージャーを使う：複雑なパスワードを覚える必要がなくなり、安全に管理できます。
    • 二段階認証を設定する：パスワードが漏れても、不正ログインを防ぎやすくなります。
    • 定期的に変更する必要はない：かつては「パスワードは定期的に変えるべき」とされていましたが、現在は推奨されていません。定期変更を強制すると、覚えやすい単純なパスワードや、末尾の数字だけを変えたパスワードを使いがちになり、かえって安全性が下がるためです。大切なのは、サービスごとに使い回さない、長く推測されにくいパスワードを設定することです。ただし、サービスからの流出や不正ログインなど、パスワードが漏れた事実がある場合は、すぐに変更しましょう。

    よくある質問

    生成したパスワードはどこかに保存・送信されますか？

    いいえ。パスワードはお使いのブラウザ内でのみ生成され、サーバーへの送信や保存は一切行いません。

    パスワードは何文字にすればよいですか？

    一般的なWebサービスでは英大文字・小文字・数字・記号を含む16文字以上を推奨します。金融サービスや管理者アカウントなど重要な用途では20文字以上がおすすめです。

    パスワードは定期的に変更したほうがよいですか？

    いいえ、定期的な変更は不要です。総務省やNIST（米国国立標準技術研究所）も、定期変更を求めない方針を示しています。使い回しのない強力なパスワードを設定し、サービスからの流出など漏えいの事実があった場合にすぐ変更しましょう。

    どのくらい安全な乱数を使っていますか？

    ブラウザ標準の暗号論的に安全な乱数生成器（Web Crypto API の crypto.getRandomValues）を使用しています。

    記号が使えないサービスではどうすればよいですか？

    強度「中」を選ぶか、詳細設定で記号のチェックを外してください。その分、文字数を長めにすると強度を保てます。
